## The Best Way to Use FLASH-UI Without Creating Digital Junk Drawer Syndrome 🧨

Use this naming pattern for each generated project:

```text
[brand]-[audience]-[asset-type]-[version]
```

Examples:

```text
moonshine-partner-portal-v1
moonshine-funding-calculator-library-v1
darwin-hanneman-launch-kit-v1
loan-broker-commission-calculator-v1
business-credit-dashboard-v1
```

Use this folder structure after export:

```text
/project-name
  /static
    index.html
    styles.css
    script.js
  /source-prompt
    flash-ui-prompt.md
  /notes
    use-case.md
    deployment-notes.md
```

That way every generated site has the **prompt, files, purpose, and deployment notes** attached. Otherwise, 40 shiny zip folders become a digital landfill with prettier CSS.
